# 兼容性

| 组件 | 原文记录的验证范围 |
| --- | --- |
| Python | 在 3.13 测试，代码面向 3.11+，未使用更高版本语法。CI 配置覆盖 3.11–3.13，原文尚未确认 CI 实际运行结果。 |
| 操作系统 | 在 Windows 11 测试。CI 配置覆盖 Linux、macOS 和 Windows，原文尚未确认 CI 实际运行结果。 |
| 客户端 MCP 协议版本 | 2024-11-05、2025-03-26、2025-06-18、2025-11-25，取决于安装的 `mcp` 包。客户端请求未知版本时使用最新支持版本。 |
| `mcp` 包 | 原文记录为 1.28，仅用于协议版本常量。分帧和路由在 `adapters/mcp/frames.py` 与 `upstream.py` 实现，以便在解析前检查批处理、重复键、大小和 ID 关联。 |
| 传输 | 面向服务器支持 stdio、Streamable HTTP，面向客户端支持 stdio。 |
| LangGraph | 英文原文将其列为 v0.2 计划，尚未给出已验证版本范围。 |

设计文档提及 MCP 2026-07-28 规范。实现使用上表中的协议版本。依赖较新会话语义前，应核对规范并重跑集成测试。

框架适配器的开发进度可能先于本表更新。源文件存在不代表已经完成兼容性验证。
