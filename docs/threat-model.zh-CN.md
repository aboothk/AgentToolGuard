# 威胁模型

[English](threat-model.md) · 简体中文

## 攻击者能力

攻击者可以控制网页和搜索结果、MCP 服务器的工具定义及响应，以及智能体能够读取的文档和记忆。

模型假定攻击者不能控制 AgentGuard 进程及宿主机、锁文件和策略文件、用户的真实授权或审批通道。

## 攻击与防护

| 编号 | 攻击 | 防护 | 强度 |
| --- | --- | --- | --- |
| A1 | 审批后替换工具定义（rug-pull） | 比较摘要，隐藏变更工具 | 确定性 |
| A2 | 新增恶意工具 | 隐藏锁文件外工具 | 确定性 |
| A3 | 同名工具遮蔽其他工具 | 强制 `server__tool` 命名空间 | 确定性 |
| A4 | 工具描述投毒 | `lock diff`、`lock approve` 提示 | 启发式，辅助人工审核 |
| A5 | 调用主体无权使用的工具 | `grants` 与参数规则 | 确定性 |
| A6 | 发送受保护原文或编码数据 | 值匹配后拒绝 | 对受支持的值、片段和常见编码确定性检测 |
| A7 | 改写后发送受保护数据 | 根据会话接触情况请求审批 | 依赖人工 |
| A8 | 不可信内容诱导危险操作 | 读取 untrusted 后，危险工具需审批 | 依赖人工 |
| A9 | 伪造或重放响应 | 关联请求 ID，ID 仅消费一次，丢弃迟到响应 | 确定性 |

## 防护范围之外

绕过网关的流量、被完全攻陷的服务器自身的数据、客户端通道、极慢外泄，以及用户错误批准的操作，详见[实现限制](limitations.zh-CN.md)。

## 实现约束

- 客户端不能选择主体或会话，客户端提交的 `_meta`、请求头不参与身份选择。
- 未知配置字段、重复键和无效锁文件导致启动失败。
- 判定异常、未知决定以及 enforce 模式的审计失败导致拒绝调用。
- 拒绝消息仅给出原因码，命中规则的细节保留在审计日志。
- 下游进程使用过滤后的环境，禁止设置 `PYTHONPATH`、`NODE_OPTIONS`、`LD_PRELOAD` 和 `*_PROXY`。
- 拒绝批处理请求，避免绕过逐次调用检查。
